## 2. 判据 M1：P1-B 采集链开销

### 2.1 假设

- H0：ON 臂（开启 P1-A 逐样本采集）相对 OFF 臂（纯前向）的相对耗时增量**上界 ≥ 10%**。
- H1：该增量上界 < 10%。

### 2.2 统计量

每对配对观测取

```
overhead_percent_i = (ON_i - OFF_i) / OFF_i × 100
```

报告量 = `overhead_percent` 的**均值**，及其 **percentile bootstrap 95% CI**
（B = 10000，seed = 0，2.5% / 97.5% 分位）。沿用 `measure_sample_capture_overhead.py`
既有实现，**不新增统计方法**。

### 2.3 判读线（唯一通过条件）

> **PASS ⟺ 该 run 的 bootstrap 95% CI 上界 < 10.0%。**

- **只看上界，不看宽度。** 区间宽是噪声的诚实呈现，不是缺陷；决定「能否宣称开销受控」的是上界。
- **不看均值、不看中位数。** 理由见 §2.4。
- 下界不设条件：下界为负在 CPU 计时噪声下完全可能，不构成失败，也不构成「负开销」结论。
- 多 seed 汇总：**三个确认性 seed 全部满足上界 < 10%** 才判 PASS。
  仅 2/3 满足 → 标 **PARTIAL**，逐 seed 披露区间，不合并、不挑优。
- P95 / max / min 作为**披露项**，不是判据。

### 2.4 为什么用区间上界而不是均值（方法学动机）

探测数据（seed 0/1/2，各 n=120。**仅用于确定协议参数，不作确认性证据**）：

| seed | mean | std | 95% CI | min | max |
| --- | --- | --- | --- | --- | --- |
| seed0 | 2.65% | 7.59 | [1.35%, 4.08%] | −11.3% | 41.2% |
| seed1 | 2.93% | 14.51 | [0.54%, 5.69%] | −53.4% | 113.1% |
| seed2 | 2.04% | 8.82 | [0.33%, 3.52%] | −54.1% | 24.5% |

单观测散布跨零，std 达 7.6–14.5 个百分点。n=120 下均值标准误约 0.7–1.3 pp，
**用均值判 < 10% 几乎必然通过，判据失去区分力**——它区分不出「真实开销 8%」
与「真实开销 2% 但噪声大」。区间上界把噪声显式计入结论，是更保守的协议。

这是**方法学差异**，不是对任何外部工作的评价。答辩统一表述：

> 本项目采用置信区间上界作为开销约束判据，以避免仅依据中心趋势掩盖 CPU 计时噪声。

### 2.5 防偷看：确认性数据与探测数据隔离

- seed 0/1/2 的三份 `sample_overhead_result.json` 属**协议探测集**，只用于确定配对粒度、n、warmup。
- 确认性证据使用**全新 seed 3/4/5**，在本文冻结并入库**之后**采集。
- 判读线在看到 seed 3/4/5 任何结果之前即已写死。
- 禁止：跑完发现不满足后改阈值、改统计量、删观测、加跑直到满足。

## 4. 停止规则与未达成时的处置

1. **先冻结，后执行。** 本文入库之后才允许采集 seed 3/4/5。
2. **执行期间不改判据。** 任何对阈值、统计量、样本量、seed 的修改，必须新建预注册版本并说明理由。
3. **结果照实入报告。** 满足写 MET，不满足写 NOT MET，并给出完整区间与 n。
4. **未达成时的降级路径**（沿用 `docs/overhead-and-risk-plan.md` §3.3）：
   降级为「仅静态快照模式」（forward 后一次性读取，不做逐 step 实时记录），
   在 summary 中记录降级原因。**不修改阈值、不删除数据、不重跑挑选。**
5. **失败声明模板**（若 M1 为 NOT MET）：

   > 在 seed X 上，采集链相对开销的 bootstrap 95% CI 为 [a%, b%]，上界 b% ≥ 10%，
   > 按预注册判据（本文件 §2.3）判为 NOT MET，已按 §4.4 降级为静态快照模式。
   > 该结论基于 CPU 单机 n=120 配对观测，不外推到其他设备。
