# 一句话版本（给非本课题的读者）

> 我给 YOLO-Master 的 MoE/MoT/Latent 三族路由装了一套**不改模型代码**的观测设备，
> 能把每次前向里"哪些专家被选中、负载均不均匀"记录下来并存档，
> 且实测额外耗时**低于 10%**——判据在跑实验之前就写死并冻结了。

---

## 1. 到底做了什么

模型里有"路由器"，决定每个 token 交给哪个专家算。以前想知道路由器怎么工作，
得改模型源码（有风险、且不符合课题的"零侵入"红线）。

我做的东西挂在模型**外面**，像夹在电线上的电流表：

- 不动 `ultralytics/` 一行代码（零侵入，课题硬性要求）
- 支持 **MoT / MoE / Latent** 三族，共 15 个模块，逐层记录
- 两种精度：**整批汇总**（快）+ **逐样本明细**（慢，但能看单个输入）

## 2. 凭什么相信数字是真的

| 环节 | 做法 |
| --- | --- |
| 每次运行 | 单独一个目录，产出 `environment.json` + `config.resolved.yaml` + 完整日志 |
| 防篡改 | 每个文件算 SHA-256 存进 `manifest.sha256.json`，一条命令可复核 |
| 防自己骗自己 | **判据先写死再跑实验**，冻结在 git 里（含 blob 哈希），事后不能改口径 |
| 指标正确性 | 14 条闭式解真值断言：`[1,0,0]` → 熵必为 0、Gini 必为 2/3 等 |
| 自动化 | GitHub Actions 每次提交跑 173 个测试（Python 3.9 与 3.12 / Ubuntu） |

## 3. 关键结果

**开销（采集功能开着 vs 关着，同一设备对比）**

| seed | 平均开销 | 95% 置信区间上界 | 判据（上界 < 10%） |
| --- | --- | --- | --- |
| 3 | 2.539% | 4.199% | 通过 |
| 4 | 2.157% | 3.325% | 通过 |
| 5 | 3.389% | 4.896% | 通过 |

**为什么用"置信区间上界"而不是"平均值"**：CPU 计时抖动大
（单次观测标准差 6.6–9.5 个百分点），只看平均值几乎必然通过，
分不出"真开销 8%"和"真开销 2% 但测得很吵"。上界判据把噪声显式算进去，更保守。

**训练 slowdown（补充测量，真实训练）**

在 coco8 上真跑训练：3 个 seed × 26 epochs，ABBA 块级配对（OFF→ON→ON→OFF），
6 组配对观测。判据同样是「CI 上界 < 10%」，同样在跑之前冻结。

| 统计量 | 值 |
| --- | --- |
| 平均 | −5.38% |
| 中位数 | −4.76% |
| 95% 置信区间 | [−15.93%, **+6.12%**] |

**判定：通过**（上界 6.12% < 10%）。注意：平均值为负是测量噪声，
不代表"开了观测反而更快"——区间跨越 0，所以**不宣称"零减速"**。

**路由平衡干预（独立实验，正式结论：NOT PASS）**

接在上面两条之后，另跑一个独立实验：只把 MoE 平衡损失的权重
（`moe_loss_fn.balance_loss_coeff`）从 baseline 1.0 调到 intervention 4.0，
看路由负载会不会变匀。条件：coco8（**4 张训练图 + 4 张验证图**）、640 / batch 1 /
CPU / workers 0、12 epochs（2 warmup + 10 measured）、3 seeds × 2 arms。
指标是 Gini / 归一化熵 / top1 share，按 seed 配对做 bootstrap 95% 置信区间。

| 统计量 | 值 |
| --- | --- |
| mean layer-Gini | 0.835790 → 0.836412 |
| mean delta | +0.000622 |
| 95% 置信区间 | [+0.000000, +0.001865] |
| 归一化熵 | 0.061679 → 0.058923 |

**判定：NOT PASS**（预注册判据未满足）。主要原因之一是天花板效应：
180 行测量里有 143 行已经顶在 Gini 上限（seed 1/2 两臂三层全饱和），
这个 regime 下几乎没有可动空间。这是**独立实验**，与上面的训练 slowdown
补充测量分开记；详细口径见 `docs/routing-balance-intervention.md`。

**P0 闭环**：seed 0/1/2/3/4/5 六次运行全部通过，manifest 校验全过。

## 4. 诚实说明：没做什么

- **训练 slowdown 是补充测量，不作为验收依据**——任务书把这条正式结论列在范围外，
  所以数字照报，但项目不靠它领功。
- **P2（token 级热图 + 演示视频）原列此清单，已于 09-12 结题冲刺补做**：MoE 空间路由热图
  叠加 COCO8 原图（`artifacts/figures/p2/`，`figure_version` 1.1.0）+ 100 秒演示视频
  （`artifacts/demo/`）。P2 属超出初始 P1 范围的新增成果，此处如实记录其原为「没做」。
- 三个 CI 下界都是正数，所以**不宣称"零开销"**。
- 测量是固定 OFF→ON 单顺序，存在未标定的顺序效应（已在判定文档中写明）。

