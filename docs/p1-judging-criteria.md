# E3 训练 Slowdown：预注册判据（Judging Criteria）

> **性质声明**：本文档是**预注册判据（pre-registered judging criteria）**，
> 不是实验结果，不包含任何实验证据或数据。判据在正式实验开始前冻结，
> 正式实验及其结果须另文如实记录，不得用本文档冒充实验结果。

## 1. 适用范围与实验目标

- **目标：training slowdown** —— 度量“路由采集/观测链路开启（ON）相对关闭
  （OFF）对训练造成的减速”。
- 适用对象：即将进行的**训练 slowdown 正式实验**。它与已归档的
  P0 overhead（hook 开关前向计时）和 P1-B 逐样本采集 overhead
  （推理侧采样链测量，`docs/p1-a-closure.md`、`docs/p1-spec.md` §7）是
  **不同实验**，本文档不重述、不覆盖、不修改任何既有协议/证据/结论。
- 仓库既有文档（`docs/p1-spec.md` §10、`docs/requirements.md`、
  `docs/smoke-design-and-schema.md`）曾将“训练减速 <10% 的正式结论”排除在
  早期 P1 范围之外；本文档为该结论补上预注册判据，不撤销既有排除声明。
- **范围内的**开销判据（采集链开销 <10%）另见
  `docs/p1-b-overhead-judging-criteria.md`。两份预注册的被测对象不同，
  不可互相引用或互相顶替；本文档仅适用于训练 slowdown。

## 2. 固定实验设计

- **Seeds**：0 / 1 / 2（固定 3 个 seed；编号与 `docs/p0-three-seed-evidence.md`
  一致）。
- **配对方式**：ABBA 块级配对——每个 seed 内按 ABBA 顺序交替运行 OFF/ON 块，
  用相邻块配对差值抑制随时间的慢漂移。
- **Workload**：ON 与 OFF 使用**相同 workload**（相同模型、相同数据、相同
  batch、相同步数/迭代数）；唯一差异是观测链路开关。

## 3. 固定统计与通过判据

- **报告**：slowdown 的**点估计**（例如配对差值归一化的均值）+ **bootstrap
  95% CI**。
- **唯一通过判据**：**95% CI 上界 < 10%**。不存在其他通过/失败口径
  （不按点估计、不按单次 run、不做人工判定）。
- **判据冻结**：判据在正式实验开始前冻结；结果出来后**不得根据结果修改
  判据**。

## 4. 诚实报告要求

- 结果**无论通过/失败都如实报告**；失败 run、异常值、波动与 FAIL 判定均须
  保留并写入实验记录，不隐藏、不挑数重跑、不把失败伪装成通过。

## 5. 限制说明（预先声明）

- 环境为 **CPU**（`device=cpu`）。CPU 计时噪声大（系统负载、频率、进程调度
  等），slowdown 数值含测量噪声；bootstrap 95% CI 反映的也是该噪声下的
  不确定性。
- 结论仅适用于本次 CPU 实验环境与所用 workload，不外推到 GPU / 分布式 /
  其他数据集。
- 本文档不改变 P0/P1-B 已归档的测量口径与“不做未预注册阈值结论”的边界。

## 6. 变更纪律

- 本文档冻结后如需修改（workload、seed、配对方式、统计方法、阈值等），必须
  先更新本文档并重新预注册，再执行正式实验；不得用新判据回溯判定已归档 run。
